# homebrew-tap

t4kamuna の Homebrew tap です。

## インストール

```sh
brew install t4kamuna/tap/mictape
```

## 収録しているもの

- [mictape](https://github.com/t4kamuna/mictape): マイクの音声を .m4a に録音するコマンドラインツール

## 必要な環境

- macOS 14 以降
- Swift 6（Command Line Tools だけでも可: `xcode-select --install`）

インストール時にソースからビルドします。
